# CREDITS — 变形记 · 厨房这一侧

**本作品为改编游戏，非原著。**

- 原著：Franz Kafka, *Die Verwandlung*（1915，Kurt Wolff Verlag, Leipzig）。
  卡夫卡逝于 1924 年，原著已在全球进入公有领域。
- 引文：游戏内所有原文引用取自 1915 年德文初版；中文译文为改编者自译。
  工作阅读使用过 David Wyllie 英译本（Project Gutenberg #5200，带版权、可自由非商业分发），
  该译本文字未进入本产物。
- 剧本、台词、旁白：入戏.skill 原创改编（MIT）。
- 美术：无外部素材。立绘为引擎内置抽象剪影（内联 SVG），背景为程序化渐变。
- 玩家角色说明：帮厨女孩确为原著人物（第二章：「这个约十六岁的女孩勇敢地坚持留了下来」）。
  尾声「你回来取工钱的那一天」为改编发明，游戏内已如实标注；那一天发生的每件事均出自原著第三章。
