# 操作单 2 · 写本（阶段 3）

## 开写前
1. 文风档案（30 分钟，五行）：平均句长与节奏 / 叙述温度 / 细节癖好 / 对白礼制 / 禁用词。
2. 把每场的原文段落摘到手边（loc + 原语言短句 ≤60 字 + 自译）。
3. cast 表：hue 同场差 ≥40，shape 五选一；玩家 id 固定 `me`；
   立绘不该出现的角色照进 cast，只要永不发言即可。

## 写作循环（每场）
- 场锚 source 先填，再写正文——先有出处，后有戏。
- 台词 ≤90 字/行；旁白短句；情绪=动作。
- 选择点自查：
  - [ ] 两个选项是同一句话的两种解读，不是道德题
  - [ ] 每个 option 有 source（没有 → 删选项或另找原文）
  - [ ] 正典侧在场，echo 写「原著里你就是这么做的」
  - [ ] u 增量：加分贴原著人物逻辑，不贴现代直觉
- 变体场景（sXa/sXb）承载状态，最多两组；想加第三组 = 该收束了。

## 收尾
- endings：恰好 1 个 canon；发明的日子在 source.loc 诚实标注。
- verdict：每轨 2-3 档，低档 = 「你和书里的人读的是同一本书」。
- 跑 `python3 tools/build_html.py script.json --check`，零错误才算写完。
