# 改编方法论 — 从一本书到一场戏

给执行入戏.skill 的 agent 读。每一节都是操作规程，不是理念抒情。
《变形记》demo（`demos/metamorphosis/`）是本文全部规则的实例，随时对照。

## 0. 五条主张（违反任何一条 = 产物退化成同人文生成器）

1. **不覆盖全书，只取五到八场戏。**
2. **玩家默认演原著里被略过的边角人物。**
3. **每个分支点必须指得回原文的一句话。**
4. **不做好感度，做理解度。**
5. **结局里必须有一条是原著真实发生的事。**

---

## 1. 选戏：先机械，后人工

**先跑 `tools/scan_scenes.py`，再读书。** 压强表告诉你哪几章值得精读——
模型不需要读完 30 万字，只需要读入选的 5-8 章加上人物首次登场章。

压强公式偏爱「话密、来回多、人少」的对峙戏。它会漏掉两类好戏，人工补：
- **沉默的重场**（《变形记》第二章对白只占 3%，但送饭体制全在这一章）——看词数大、
  对白低、主角在场的章，快速扫开头判断；
- **信息爆点**（一封信、一次死讯）——交锋少但改变一切，通常紧跟在压强高峰前后一章。

选出的场景串成一条 30-60 分钟的线。**场与场之间的时间跳跃直接写在场景标签里**
（「两周后」「又一个多月后」），不要用过场戏填缝——书里没有的日常，游戏里也不要有。

## 2. 定角：玩家演谁

三选一，**开工前必须和用户确认**，默认第二种：

| 玩家身份 | 适用 | 代价 |
|---|---|---|
| 原著主角 | 书本身第一人称、玩家就想「成为他」 | 玩家知道结局，选项没悬念；一改就不是那个人 |
| **边角人物（默认）** | 绝大多数小说 | 需要从原文里把这个人找出来 |
| 全新外来者 | 原著人物全员不可用时的下策 | 和原著关系最弱，极易滑成同人文 |

**找边角人物的方法**：grep 原文里的仆人、信使、店员、邻居、无名代词——找那种
「出现 2-5 次、每次都在关键场景边缘、没有内心描写」的人。检验标准三条：
- 关键场景她**在场或可以合理在场**（她的职务/身份决定）；
- 原著给过她**至少一个主动动作**（那就是她的正典选择，游戏的题眼）；
- 她的选择**改变不了主线**（主线大事必须照常发生——玩家改变的是缝隙，不是历史）。

《变形记》的帮厨女孩满分通过：原文给了她五个锚（勇敢留下 / 求准锁厨房 / 被支开 /
肯定不会帮 / 终被辞退），而她锁上厨房门这个动作，反过来变成整个游戏的中心问题——
**如果你不锁那扇门呢？**好的玩家角色都自带这样一个问题；找不到这个问题，就换人。

## 3. 分支：长在原文上

每个选择点的生产流程：

1. **找原文里的「本可以」**——一个人物做了 A，而文本的缝隙里存在 B：
   - 原文**断言**的行为（「女仆是肯定不会帮她的」→ 你偏要帮）；
   - 原文的**歧义**（父亲喊「安娜！」但没写谁应声 → 谁去？）；
   - 原文**沉默**的地方（没有人追下去还协理的帽子 → 你追）。
2. **写进 option.source**：loc + 原文短句 + 译文。找不到出处的选项**删除**，没有例外。
3. **正典侧永远是选项之一**。玩家永远可以选「书里真实发生的那个」，echo 告诉他
   「原著里，你就是这么做的」。偏离侧的 echo 明说「从这一刻起，你离开了书页」。
4. **偏离不改主线**。偏离改变的是：你看见了什么、你和谁说了话、结算时你被判定读懂了
   多少。苹果照样砸进背里，死照样在三月末。若一个分支会阻止主线事件，砍掉它。

**发明的场景要诚实标注。**玩家线允许存在原文没有的一天（《变形记》尾声：你回来取
工钱那天），但 source.loc 必须写明「这一天你在场，是书页之外的事；这一天发生的
每件事，都是书里的」。诚实的发明是改编，伪装成原文的发明是造假。

**分支收束纪律**：全游戏选择点 5-9 个；带路线分岔的 ≤ 3 个（其余选择改变理解度与
echo，不改变去向）；状态用「场景变体」承载（s5a/s5b），不引入变量系统——两个状态
分岔相乘就是四个变体场景，写不动的时候就是该收束的时候。

## 4. 理解度：选项是解读，不是讨好

写选择肢时自查三问：

- 这两个选项是**对同一句话/同一个人的两种解读**吗？（是 → 合格；
  是「善良 vs 刻薄」的道德题 → 重写）
- 加分的那个选项，**贴的是原著人物逻辑**还是现代读者的道德直觉？
  （《变形记》递汤给「它」减葛蕾特的分——因为打扫他的房间是她一个人的事，
  你越界了。懂一个人和讨好一个人经常相反。）
- 有没有「两个都对、但不能全要」的选择？每个游戏至少要有一个——理解是有代价的，
  这是理解度和好感度的分水岭。

判词（verdict）写法：冷静、贴原文、不奉承。低档判词不是骂玩家，是指出
「你和书里的人读的是同一本书」——大多数误读都是原著人物自己的读法。

## 5. 文风：克隆原著，不是轻小说腔

开写前先做 30 分钟文风档案（写进工作笔记，不进产物）：

- **句长与节奏**：原著平均句长、长短句怎么交替；
- **叙述温度**：情绪写成动作还是形容词？（卡夫卡：冷静的公务腔说可怕的事，零感叹）；
- **细节癖好**：作者反复精确到什么？（卡夫卡：钟点、钱数、制服纽扣）；
- **对白礼制**：人物之间怎么称呼、哪个阶层说话带敬语。

旁白全部按档案写。台词一行 ≤ 90 字——视觉小说的节奏是一次一口。
禁用词表：任何原著语境里不存在的现代词、网络腔、翻译腔感叹（「天哪这真是太……」）。

## 6. 版权：写进流程的四步

1. **判定**：查作者卒年 + 首次发表年。美国线：1930 年及以前发表 → 公有领域（2026 年起，
   逐年 +1）；多数其他法域：作者死后 50 或 70 年。判定结果写进 `meta.book.pd_status`：
   `public-domain-worldwide` / `public-domain-us` / `copyrighted-local-only`。
   拿不准 → 按 copyrighted 处理。产物只给用户本地玩，构建器会注入「仅限本地自娱」页脚。
2. **译本陷阱**：原著公版 ≠ 译本公版。引用原文一律引**原语言初版**（公版），
   译文自译。《变形记》demo 全部引文是 1915 德文初版 + 自译，Wyllie 英译只用于
   工作阅读，一个字不进产物。
3. **不内嵌全文**：产物里的原文只有 source 里的短句（每条 ≤ 60 字）。剧本正文全部原创。
4. **署名**：`meta.credits` 写明「本作品为改编，非原著」+ 原著出处；构建器把它渲染进
   结算页和页脚。

## 7. 适配范围（对用户诚实）

- 小说、戏剧：主打。戏剧尤其顺（本身就是场次+对白）。
- 传记、历史非虚构：可做，「你是当时在场的某个人」，分支点指向史料而不是虚构文本。
- 科普、工具书、论文集：**不适合，直接告诉用户不适合**。没有人物就没有理解度，
  没有叙事就没有正典结局——两条主张同时失效的书不要硬做。

## 8. 体量基准（《变形记》demo 实测，做完新 demo 要回填修订）

| 量 | 值 |
|---|---|
| 场景 | 10-13 个（含 2-3 组变体场景） |
| 选择点 | 8-10 个，其中路线分岔 ≤ 3 |
| 结局 | 3 个（1 正典 + 1 提前离场 + 1 深度偏离） |
| 台词/旁白正文 | 3,800-6,000 字（不含选项与出处） |
| 一周目时长 | 15-25 分钟 |
| 理解度轨道 | 3-4 个角色，总计分点 10-14 处 |
