# Pendo Headless Components Reference

Headless custom elements and runtime helpers for building block guide code blocks. These handle
poll data collection and guide action dispatch without rendering any UI — the visual layer is
entirely custom HTML/CSS generated by the skill.

---

## Overview

| Component / Pattern | Purpose | Renders |
|---------------------|---------|---------|
| `<pendo-poll>` | Declares a poll field and stores its value | Nothing |
| `actions` factory (inline JS) | Orchestrates poll submission, guide navigation, and `guideActivity` analytics via `step.trackAction` | N/A — plain object |

`<pendo-poll>` is a custom element registered via an inlined IIFE in the script block.
The `actions` object is a plain JS factory created fresh inside each step's script wrapper —
no global registration, no custom element, no cross-step pollution.

---

## `<pendo-poll>`

Declares a single poll data field. One element per question/input in the guide.

### Attributes

| Attribute | Required | Description |
|-----------|----------|-------------|
| `poll-id` | Yes | Unique poll identifier. Format: `cb-{Type}-{shortRandom}` |
| `type` | Yes | Data type being collected (see table below) |
| `question` | Recommended | Prompt text shown to the user, copied from the visible question label. Surfaces on the guide Poll Metrics page. Without it the metrics question column is blank. |
| `scale` | Recommended for `NumberScale` | The rating range as `min-max` (e.g. `1-5`, `0-10`), matching the visible rating UI. Lets the metrics distribution chart render its scale buckets. Not needed for `Boolean` (defaults to 0/1) or text/choice types. |

### Supported Types

The `type` attribute describes the *data shape* being collected. The component internally maps
each type to the appropriate Pendo backend poll type for `step.response()`.

| Type | Data Shape | Pendo Backend Type | Serialization |
|------|-----------|-------------------|---------------|
| `NumberScale` | integer (ratings, scales, NPS) | `NumberScale` | integer as-is |
| `FreeForm` | string (open text) | `FreeForm` | string as-is |
| `SingleChoice` | string (one selected option) | `FreeForm` | string as-is |
| `MultiSelect` | array of strings | `FreeForm` | JSON stringified array |
| `Boolean` | true/false | `NumberScale` | `1` or `0` |
| `Ranking` | ordered array | `FreeForm` | JSON stringified array |

### Methods

| Method | Returns | Description |
|--------|---------|-------------|
| `.setValue(value)` | void | Stores the value in its native JS type |
| `.getValue()` | any | Returns the stored value in its native JS type |
| `.getSerializedValue()` | string or number | Returns the value serialized for `step.response()` |
| `.hasValue()` | boolean | Returns true if a non-empty value is stored |

### Properties

| Property | Description |
|----------|-------------|
| `.pollId` | Reads the `poll-id` attribute |
| `.type` | Reads the `type` attribute (data shape) |
| `.backendType` | Returns the Pendo backend type this maps to (`NumberScale` or `FreeForm`) |

### Events

| Event | Detail | Description |
|-------|--------|-------------|
| `pendo-poll-change` | `{ pollId, value, type }` | Fires on every `.setValue()` call. Bubbles. |

### Usage

```html
<pendo-poll poll-id="cb-NumberScale-e7a21f04" type="NumberScale" scale="1-5" question="How likely are you to recommend us?"></pendo-poll>
<pendo-poll poll-id="cb-SingleChoice-a1b2c3d4" type="SingleChoice" question="Which channel do you use most?"></pendo-poll>
<pendo-poll poll-id="cb-MultiSelect-f5e6d7c8" type="MultiSelect" question="What do you value most?"></pendo-poll>
<pendo-poll poll-id="cb-FreeForm-b8c93d12" type="FreeForm" question="What would make it better?"></pendo-poll>
```

```javascript
// NumberScale — pass an integer
document.querySelector('[poll-id="cb-NumberScale-e7a21f04"]').setValue(4);

// SingleChoice — pass the selected option string
document.querySelector('[poll-id="cb-SingleChoice-a1b2c3d4"]').setValue('Google');

// MultiSelect — pass an array of selected options
document.querySelector('[poll-id="cb-MultiSelect-f5e6d7c8"]').setValue(['Price', 'Quality']);

// FreeForm — pass a string
document.querySelector('[poll-id="cb-FreeForm-b8c93d12"]').setValue('Great experience!');
```

## `actions` Factory (Inline JS)

A plain JavaScript object created fresh inside each step's script wrapper IIFE. It closes over
the correct `step`, `guide`, and `pendo` references from the IIFE parameters — zero global state,
zero custom element registration, zero cross-step pollution.

### Why not a custom element?

`customElements.define()` is permanent and global. If any guide on the page registers an older
version of an actions class first, subsequent guides inherit that stale definition. By using a
plain JS factory, every step gets its own fresh `actions` object with guaranteed-correct references.

### Methods

Each method takes the clicked element itself (`this` from the handler) as its first argument, so the
factory can derive the `elementId` (id) and `elementType` (tag) it passes to `step.trackAction`.

| Method | Parameters | Description |
|--------|-----------|-------------|
| `actions.submit(el)` | el (clicked element) | Collects `<pendo-poll>` values, calls `step.response()`, reports a single `submitPoll`, then `step.advance()` |
| `actions.advance(el)` | el (clicked element) | Reports `advanceGuide`, then calls `step.advance()` |
| `actions.previous(el)` | el (clicked element) | Reports `previousStep`, then calls `pendo.onGuidePrevious()` |
| `actions.dismiss(el)` | el (clicked element) | Reports `dismissGuide`, then calls `step.dismiss()` |
| `actions.snooze(el, duration)` | el, duration (ms, default 86400000) | Reports `guideSnoozed`, then calls `pendo.onGuideSnoozed(guide.id, step.id, duration)` |
| `actions.openLink(el, url, target)` | el, url (string), target (default '_blank') | Reports `openLink`, then triggers openLink via event router |

### Analytics via `step.trackAction`

Code-block guide clicks are not visible to Pendo's automatic click-capture path, because the injected
HTML buttons are not nodes in the guide's `domJson` tree. To close this gap, each action reports a
`guideActivity` event through `step.trackAction(...)` — a public step method — before performing the
behavior. The `track()` helper wraps this call and is guarded (`if (step.trackAction)`) so guides still
work on agents that predate the method. `step.trackAction` accepts
`{ elementId, elementType, actions }` and stages a `guideActivity` event (recorded as
`uiElementId`/`uiElementType`), matching the shape produced by Pendo's native
building-block click path. Guide metrics displays deleted code-block elements by their element id
(no visible text is captured).

`actions.submit` sends a single `submitPoll` action; guide metrics expands that into
"Submit Poll & Next Step", so there is no separate advance event for the same click.

### Companion `data-pendo-action` attribute

`trackAction` only fires on click, so an element has no recorded Action until someone clicks it. To make
guide metrics show the Action for code-block elements even with zero clicks, also stamp each interactive
element with a `data-pendo-action` attribute — a JSON array of the same guideActivity action(s) the
element reports (e.g. `data-pendo-action='[{"action":"advanceGuide"}]'`). Guide metrics reads it straight
from the stored HTML. Keep it in sync with the `actions` call the handler makes; for submit buttons list
only `submitPoll`. See "Element action metadata" in `references/html-generation.md` for the full mapping.

### Factory Template

Place this at the top of the IIFE:

```javascript
(function(step, guide, pendo) {
  var polls = document.querySelectorAll('pendo-poll');

  function track(el, acts) {
    if (!step.trackAction || !el) return;
    step.trackAction({ elementId: el.id, elementType: el.tagName, actions: acts });
  }

  var actions = {
    submit: function(el) {
      var responses = [];
      polls.forEach(function(p) {
        if (p.hasValue()) responses.push({ pollId: p.pollId, value: p.getSerializedValue() });
      });
      if (responses.length) step.response(responses);
      track(el, [{ action: 'submitPoll' }]);
      step.advance();
    },
    advance: function(el) { track(el, [{ action: 'advanceGuide' }]); step.advance(); },
    previous: function(el) { track(el, [{ action: 'previousStep' }]); pendo.onGuidePrevious(); },
    dismiss: function(el) { track(el, [{ action: 'dismissGuide' }]); step.dismiss(); },
    snooze: function(el, d) { d = d || 86400000; track(el, [{ action: 'guideSnoozed', duration: d, timeUnit: 'ms' }]); pendo.onGuideSnoozed(guide.id, step.id, d); },
    openLink: function(el, url, target) {
      target = target || '_blank';
      track(el, [{ action: 'openLink', url: url, target: target }]);
      step.eventRouter.eventable.trigger('pendoEvent', {
        action: 'openLink', step: step,
        params: [{ name: 'url', value: url }, { name: 'target', value: target }]
      });
    }
  };

  // ... step-specific logic using actions.advance(this), actions.submit(this), etc.
})(step, guide, pendo);
```

### Usage Examples

```javascript
// Submit all polls then advance (single guideActivity event)
document.getElementById('pendo-button-4d5e6f7a').addEventListener('click', function() {
  actions.submit(this);
});

// Dismiss (corner X — use a pendo-close-guide-<hash> id so it classifies as Close Button)
document.getElementById('pendo-close-guide-1a2b3c4d').addEventListener('click', function() {
  actions.dismiss(this);
});

// Open external link
document.getElementById('pendo-button-9c0d1e2f').addEventListener('click', function() {
  actions.openLink(this, 'https://docs.example.com', '_blank');
});

// Snooze (default 1 day)
document.getElementById('pendo-button-3c4d5e6f').addEventListener('click', function() {
  actions.snooze(this);
});
```

### Error Handling

`actions.submit()` relies on `step.response()` existing. If `pollIds` are not configured on the step
in Pendo, `step.response` will be undefined. The generated HTML includes a deployment comment
at the top listing required poll IDs to prevent this.

---

## Poll ID Format

All poll IDs follow this convention:

```
cb-{Type}-{shortRandom}
```

| Segment | Description | Example |
|---------|-------------|---------|
| `cb` | Prefix indicating "code block" origin | `cb` |
| `{Type}` | The data type being collected | `NumberScale`, `FreeForm`, `SingleChoice`, `MultiSelect`, `Boolean`, `Ranking` |
| `{shortRandom}` | 8-character random hex string | `e7a21f04` |

Full examples:
- `cb-NumberScale-e7a21f04`
- `cb-FreeForm-b8c93d12`
- `cb-SingleChoice-a1b2c3d4`
- `cb-MultiSelect-f5e6d7c8`
- `cb-Boolean-9a8b7c6d`
- `cb-Ranking-3e4f5a6b`

---

## Deployment Requirement

The generated poll IDs **must** be registered in the step's `pollIds` array in the guide
configuration. Without this, `step.response()` will not be attached to the step object by
Pendo's Poll behavior mixin, and `actions.submit()` will fail with a console error.

When deploying a generated guide:
1. Note all `poll-id` values from the `<pendo-poll>` elements
2. Add each ID to the step's `pollIds` array in the guide JSON
3. Configure matching poll entries in `guide.polls` with the correct `attributes.type`

## Component Registration

The registration block is inlined at the top of the `<script>` tag. It uses a guard
(`customElements.get('pendo-poll')`) to prevent duplicate registration if multiple steps
on the same page use the component. Only `<pendo-poll>` is registered as a custom element —
the `actions` helper is a plain JS object (see above).

```javascript
/*BEGIN COMPONENT REGISTRATION*/
(function(){if(customElements.get('pendo-poll'))return;var B={NumberScale:'NumberScale',FreeForm:'FreeForm',SingleChoice:'FreeForm',MultiSelect:'FreeForm',Boolean:'NumberScale',Ranking:'FreeForm'};class PendoPoll extends HTMLElement{connectedCallback(){this.style.display='none';this._value=undefined}get pollId(){return this.getAttribute('poll-id')}get type(){return this.getAttribute('type')}get backendType(){return B[this.type]||'FreeForm'}setValue(v){this._value=v;this.dispatchEvent(new CustomEvent('pendo-poll-change',{detail:{pollId:this.pollId,value:v,type:this.type},bubbles:true}))}getValue(){return this._value}getSerializedValue(){var v=this._value;if(v===undefined||v===null)return undefined;switch(this.type){case'NumberScale':return typeof v==='number'?v:parseInt(v,10);case'Boolean':return v?1:0;case'MultiSelect':case'Ranking':return Array.isArray(v)?JSON.stringify(v):String(v);default:return String(v)}}hasValue(){if(this._value===undefined||this._value===null)return false;if(this.type==='MultiSelect'||this.type==='Ranking')return Array.isArray(this._value)&&this._value.length>0;return this._value!==''}}customElements.define('pendo-poll',PendoPoll)})();
/*END COMPONENT REGISTRATION*/
```

## Complete Code Block Structure

A generated code block using these components follows this layout:

```html
<style id="pendo-inline-css" type="text/css">
  /* Custom visual styles */
</style>

<!-- Visual HTML (fully custom, skill-generated) -->
<div class="guide-container">
  <!-- Custom UI for polls, buttons, content -->
</div>

<!-- Data layer (invisible, only for poll guides) -->
<pendo-poll poll-id="cb-NumberScale-e7a21f04" type="NumberScale" scale="1-5" question="How would you rate this?"></pendo-poll>
<pendo-poll poll-id="cb-FreeForm-b8c93d12" type="FreeForm" question="Tell us more"></pendo-poll>

<script id="pendo-inline-script">
/*BEGIN PENDO PREVIEW STUBS*/
(function() {
  // Toast-based stubs for local browser preview
  // Mocks step, guide, pendo objects
})();
/*END PENDO PREVIEW STUBS*/

/*BEGIN COMPONENT REGISTRATION*/
(function(){/* ... minified PendoPoll class ... */})();
/*END COMPONENT REGISTRATION*/

(function(step, guide, pendo) {
  var polls = document.querySelectorAll('pendo-poll');

  function track(el, acts) {
    if (!step.trackAction || !el) return;
    step.trackAction({ elementId: el.id, elementType: el.tagName, actions: acts });
  }

  var actions = {
    submit: function(el) { /* collect poll values, call step.response() */ track(el, [{ action: 'submitPoll' }]); step.advance(); },
    advance: function(el) { track(el, [{ action: 'advanceGuide' }]); step.advance(); },
    previous: function(el) { track(el, [{ action: 'previousStep' }]); pendo.onGuidePrevious(); },
    dismiss: function(el) { track(el, [{ action: 'dismissGuide' }]); step.dismiss(); },
    snooze: function(el, d) { d = d || 86400000; track(el, [{ action: 'guideSnoozed', duration: d, timeUnit: 'ms' }]); pendo.onGuideSnoozed(guide.id, step.id, d); },
    openLink: function(el, url, target) { track(el, [{ action: 'openLink', url: url, target: target || '_blank' }]); /* trigger via event router */ }
  };

  // Wire custom UI events to poll components
  // Wire buttons to actions methods (pass this, the clicked element). Each button also carries a
  // tracked id (pendo-button-* / pendo-close-guide-*) and a matching data-pendo-action attribute.
})(step, guide, pendo);
</script>
```

### EJS template tags
**NEVER add EJS template tags** (`<% %>`, `<%= %>`) to generated output. This includes the
`guide.id`/`step.id` variable resolution block.
