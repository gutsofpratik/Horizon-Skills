# Delivery state and contract-based proposal validation

State the artifact's lifecycle explicitly: outline, working-draft, review-draft, or submission-candidate. Drafts may contain marked missing inputs with owner, consequence and next action. Missing customer resumes, signatures, evidence or pricing are legitimate draft gaps. Submission candidates fail readiness while mandatory inputs remain unresolved. A structural pass alone does not mean ready to submit.

Keep solicitation requirements separate from internal planning controls. Preserve exact requirement IDs, source type, portable source citation, verbatim requirement, interpretation, owner and response/evidence. Identify the controlling amendment and impacted requirements. Reconcile source requirement coverage; never claim complete coverage from a sampled source bundle. Keep active deadlines consistent as timezone-aware instants, preserving the source local time and zone. Mark superseded dates as history, not active instructions.

Use the existing eleven-sheet validator profile for that supplied template. For a requested four-sheet or other layout, use `python scripts/validate_proposal_workbook.py workbook.xlsx --profile contract --contract contract.json`. Use `scripts/prepare_proposal_workbook_render.py` with the same `--profile contract --contract contract.json` for arbitrary layouts; that path preserves authored print areas and computes any missing areas from all populated columns. The default preparer rejects non-template layouts before changing them. Do not force arbitrary customer workbooks into eleven sheets. Read `references/proposal-contract-format.md` for semantic column mappings. Run spreadsheet recalculation/render/coverage QA separately on the exact final file.

Synthetic control: a four-sheet Matrix/Sources/Deadlines/Gaps review draft with R2 resume TBD can pass draft checks while readiness stays unresolved. It fails as a submission candidate. An amendment moving the deadline to May 10 17:00-04:00 must replace every active May 9 control; preserve the old value only as explicitly labeled history. Include source citations and amendment impact mappings even when table positions differ.
