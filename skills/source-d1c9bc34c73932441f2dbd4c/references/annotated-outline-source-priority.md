# Annotated Outline Source Priority

Use this precedence approach unless the solicitation says otherwise.

1. Latest signed amendment or formal Q&A that modifies the solicitation.
2. Current solicitation/RFP/RFQ text.
3. Attachments incorporated by the solicitation, including PWS/SOW/SOO, CDRLs, forms, pricing templates, and portal instructions.
4. GovTribe structured opportunity metadata.
5. GovTribe related-award/incumbent context.
6. Customer-provided company/capture context.
7. Public background research.

## Conflict handling

- If two official solicitation sources conflict, flag the conflict and recommend a question to the contracting officer when still possible.
- If GovTribe metadata conflicts with the solicitation, use the solicitation for compliance and flag the metadata conflict.
- If customer win themes conflict with solicitation constraints, do not force the win theme; list it as a strategy risk.
- If a requirement has no clear proposal location, list it in “Unmapped or ambiguous requirements” and propose a location.

## Citation format

Use compact citations that a proposal manager can trace:

```text
REQ-L-007 — SRC-001 §L.4.3 p.61
REQ-M-003 — SRC-001 §M.2.2 p.77
REQ-C-014 — SRC-003 PWS §5.1 p.18
REQ-QA-002 — SRC-004 Q&A #12
GT-INC-001 — GovTribe related award record
CUST-PP-001 — Customer past performance profile
```

If page numbers are unavailable, use paragraph numbers, heading names, attachment/table numbers, or chunk IDs.
