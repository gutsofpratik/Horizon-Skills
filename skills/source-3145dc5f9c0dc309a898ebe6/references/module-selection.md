# Module selection

Read this reference when selecting or adding a Forge extension point.

Use current Forge module discovery and the exact module reference to select a supported extension point for the user outcome. Consider product placement, execution or UI model, authorization context, lifecycle status, cross-product compatibility, unlicensed access, and distribution constraints only when they affect the choice.

Do not guess module support or manifest properties. If no supported module provides the outcome, explain the constraint and present materially different supported alternatives.
