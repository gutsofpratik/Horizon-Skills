# Storage and residency

Read this reference when persistent data, caching, schemas, migration, tenant isolation, uninstall behavior, recovery, or residency matters.

Choose among current supported storage options according to the app's access patterns, data lifecycle, isolation, residency, limits, and cost requirements. Treat Preview or EAP storage as an explicit product decision.

For an existing app using legacy storage, retrieve current support and migration guidance. Separate migration from feature work unless coupling them is necessary for correctness or compatibility.

Validate the data risks introduced by the change, particularly tenant isolation, retention, uninstall or recovery behavior, and migration or lifecycle behavior. When personal data is stored, retrieve the current privacy guidance and account for reporting and erasure obligations.
