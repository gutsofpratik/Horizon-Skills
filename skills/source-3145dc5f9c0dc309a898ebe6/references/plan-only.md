# Plan-only route

Read this reference when the requested outcome is architecture, feasibility, estimation, or an implementation plan without repository mutation.

Gather only enough information to resolve feasibility and consequential design choices. Inspect an existing app when its actual architecture affects the plan, and retrieve current documentation for material Forge assumptions.

Produce a decision-ready plan that distinguishes documented facts from recommendations, identifies unresolved user decisions, and makes the implementation and release boundaries clear. Include alternatives only when they present a material trade-off.

Do not mutate the repository or external state merely to improve a plan. Stop after delivering the requested planning result.
