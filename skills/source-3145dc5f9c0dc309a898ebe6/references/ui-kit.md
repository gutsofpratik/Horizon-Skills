# UI Kit

Read this reference only for a module implemented with UI Kit or UI Kit `Frame`.

Confirm current module support and choose UI Kit when its native components and supported bridge capabilities meet the requirement. Use Custom UI when the experience materially depends on browser DOM behavior, an existing web app, or unsupported UI capabilities.

Use current component, hook, bridge, manifest, internationalization, and accessibility documentation as needed. Use `@forge/react` for UI Kit; do not treat Atlaskit packages as UI Kit components.

Validate that the manifest and implementation agree and that the changed behavior works in the relevant states.
