# Hybrid market and technology briefings

Use this handoff only when a deck or report needs both a conceptual explanation and measured evidence. An ordinary market query, export, or leaderboard does not require an illustration.

Example: a satellite communications executive brief can pair a conceptual optical-link scene with a chart of sourced award obligations by year. Describe the scene as conceptual; do not depict an exact deployed network or infer a verified equipment configuration. Keep dates, values, chart labels, important text, and source citations outside the generated image.

1. Establish the reader and decision. Contractor investment or capture leaders may need market attractiveness, uncertainty, and action choices; prospective partners may need role and capability fit; government technical readers may need mission relevance and solution tradeoffs. Honor explicit audience direction; studying an agency does not establish that agency as the reader. Carry that audience and purpose into the narrative and visual brief. Establish the market cohort, units, period, and sources through the primary market workflow. Missing values stay unknown; artwork must not conceal missing evidence.
2. Reuse the customer's established theme and approved assets. Write a self-contained visual brief specifying the audience, decision, explanatory purpose, concept, aspect ratio, composition, palette, style, caption/alt text, and factual boundaries. Generate or edit conceptual artwork only through an image capability actually available on the host. Keep data marks, scales, precise diagrams, labels, and important text deterministic and editable. Use the host's authorized image attachment/download and authoring workflow for image access; vector retrieval is for document content, not image staging. Inspect the selected image, preserve the source and edited assets at host-supplied input/output locations, and identify the selected occurrence when editing an existing artifact. For edits, inspect the actual original image bytes and preserve the exact user-selected revision; metadata or retrieved text cannot substitute for the image. If original-byte access is unavailable, provide the visual change brief and identify the missing input rather than silently editing another revision. A host-created image does not automatically have a GovTribe User File or generation identity; use only returned identifiers and never invent an upload or claim that an asset was saved without a successful authorized result.
3. Use `Show_Chart` or `Show_Stats_Display` for concise inline answers. For polished charts, use the host's deterministic chart or document/presentation capability; prefer native editable charts when editability matters. Validate the chart-ready rows, units, period, values, labels, and citations against the retrieved evidence. If inline displays are unavailable, return the same evidence in a labeled Markdown table or CSV.
4. Hand the inspected illustration, verified chart/data, and editable narrative/citations to the host's presentation, document, or PDF capability. Use `govtribe-file-templates` for approved templates, `govtribe-document-editing` for revisions, and `govtribe-govcon-writing` for audience-appropriate narrative, resolving each from its own installed skill root. Give each element its own layout area, preserve the intended aspect ratio and selected source asset, and inspect the rendered combination at final size for legibility, clipping, placement, and explanatory value.
5. Confirm the visual explains the subject without competing with the conclusion. Reuse it for text-only revisions. If image generation is unavailable, reuse an authorized supplied asset, create an appropriate deterministic diagram with an available host capability, or omit optional decoration. Disclose any explicitly requested illustration that could not be made. If authoring, rendering, or visual inspection is unavailable, preserve useful editable content, deliver any validated source artifact plus Markdown or CSV, and identify unverified rendering or missing files. Do not claim an image or document was completed merely because a fallback was produced.
