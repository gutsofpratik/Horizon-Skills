# Federal Budget Data

Use this reference when early-signal work depends on official federal budget, justification, appropriations, or planning sources.

## Goal
- Get to the current FY budget request or enacted budget artifact quickly enough to confirm funding direction, priorities, and likely procurement lanes.
- Use OMB for cross-agency totals and agency budget hubs for line-item detail and justifications.

## Workflow

### 1. Start with OMB when the scope is broad
- Use the President's Budget hub for the `Appendix`, `Analytical Perspectives`, `Historical Tables`, supplemental materials, and prior budgets.
- Use agency-specific pages only after the high-level funding lane is clear.

### 2. For each agency, prefer the current budget or performance hub
- Look for `Congressional Budget Justification`, `Budget in Brief`, `Budget Request`, `Annual Performance Report`, `Agency Financial Report`, and machine-readable budget tables.
- If the page is HTML, use the host's provider-neutral web-browsing capability to identify linked PDF, `XLS`, `XLSX`, or `CSV` artifacts. Analyze them with the host's ordinary attachment or spreadsheet capability. If those capabilities are unavailable, return the official artifact links and a labeled partial result; request a supported export only when the missing line-item evidence would materially change the answer.

### 3. Expect CMS drift and year-coded URLs
- Federal agency slugs drift often. If a listed path fails, search the same domain for `budget`, `budget performance`, `congressional budget justification`, or `agency reports`.
- If the path includes a year segment like `fy-2026` or `fy27`, roll that segment forward before broader searching.

### 4. Treat hubs as link indexes, not as the data itself
- High-value live hubs include OMB, DOI, EPA, GSA, NASA, VA, EEOC, NEH, LOC, and USAGM.
- Follow the newest current-FY document link from the hub instead of reading the whole page.

### 5. Handle unstable agencies explicitly
- `state.gov` budget pages currently return technical difficulties in some environments. If that happens, search `site:state.gov congressional budget justification Department of State` and prefer current FY appendices or budget fact sheets.
