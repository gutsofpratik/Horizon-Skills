# State Budget Data

Use this reference when early-signal work depends on official state, district, or territory budget, appropriations, or planning sources.

## Goal
- Reach the current-year budget artifact quickly enough to confirm funding direction, priorities, and likely procurement lanes.
- Prefer the deepest budget page or download index over an agency homepage.

## Workflow

### 1. Start with the current-year budget artifact
- Prefer pages titled `Executive Budget`, `Current Budget`, `Budget Book`, `Budget Documents`, `Budget Downloads`, `Appropriations`, `Capital Plan`, or `Current Biennial Budget`.
- Use the host's provider-neutral web-browsing capability to identify linked PDF, `XLSX`, and `CSV` artifacts, then analyze them with the host's ordinary attachment or spreadsheet capability before relying on landing-page prose. If those capabilities are unavailable, return the official artifact links and a labeled partial result; request a supported export only when the missing line-item evidence would materially change the answer.

### 2. Recognize the source type
- Interactive budget portals usually expose the cleanest program and line-item data. Examples: California eBudget, Massachusetts Budget Downloads, and Puerto Rico budget portals.
- Document libraries and governor or OMB hubs usually require one extra click into the current FY folder or document set.
- Transparency portals are useful for enacted spending context but may be weaker for proposed budget language.

### 3. Follow year conventions instead of generic site chrome
- Look for `FY 2027`, `FY27`, `2026-27`, `Current`, `Proposed`, `Enacted`, or `Governor's Budget`.
- If the URL itself contains a year segment like `fy27`, change that segment first before broader searching.

### 4. Use same-domain fallback when a path drifts
- Search the same domain for `budget`, `budget documents`, `appropriations`, `capital plan`, or `current budget`.
- Treat homepages, news banners, and navigation chrome as noise unless they are the only path to the budget files.

## High-Value Patterns
- California, Massachusetts, Minnesota, New York, North Dakota, Tennessee, Wisconsin, Wyoming, the District of Columbia, and Puerto Rico are strong first stops because they expose current budget pages or direct downloads with minimal navigation.
- Florida and New Mexico are better for transparency and budget detail tables than for narrative budget books.
