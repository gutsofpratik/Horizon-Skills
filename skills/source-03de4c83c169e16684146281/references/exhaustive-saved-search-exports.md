# Exhaustive saved-search exports

Choose this branch when the request says all results, complete export, every saved-search match, or a tracker universe. Preserve ranked shortlist routing for prioritization requests; do not apply shortlist exclusions to an exhaustive export. If both are requested, provide the full universe and a separately labeled ranked subset.

1. Resolve named searches with `Search_Saved_Searches`; use `Documentation` for the current result-retrieval schema, pagination and supported filters on the correct federal contract, grant or state/local search surface. Save each search ID, exact filter payload (including date inclusivity/timezone), sort, retrieval time, reported count and pagination cursor. Do not silently broaden or rewrite filters.
2. Traverse every page through the terminal cursor. Persist a page ledger: search, cursor, next cursor, IDs, count, retrieval timestamp. Detect repeated cursors and retrieval failures. A partial fetch is partial coverage, never zero matches. Save a resume checkpoint at a host-authorized location after each successful page: unchanged filter/sort contract, completed search/page IDs, next cursor, source rows and memberships, exclusions and retrieval time. On interruption, retain the checkpoint and label coverage partial. Resume from the last successful cursor when valid; if it expires or the source changes, restart that search with a new ledger and reconcile canonical IDs without silently merging incompatible snapshots. If persistent storage is unavailable, deliver the checkpoint as JSON/CSV for the user to retain and state that automatic resume was not established.
3. Union by canonical opportunity ID. Retain all source-search memberships. Keep original titles, identifiers, missing fields and source links. Reconcile fetched rows → unique IDs → prior-batch and explicitly requested exclusions → delivered IDs.
4. Apply date boundaries to timezone-aware instants. Preserve source local time and zone. Explicitly mark unknown dates rather than silently dropping them. Distinguish inactive opportunities, expired deadlines, and missing deadlines.
5. Use a spreadsheet task contract with the complete source inventory, requested column mapping and excluded identities. Validate exact delivered identity set, values, order when requested, unique entity counts and totals. A count alone cannot prove completeness. Preserve the full source inventory and separately label any ranked subset. Use the host's spreadsheet capability when available; otherwise deliver CSV plus a Markdown reconciliation summary with the same identity set and source memberships. State unsupported formatting or validation steps without claiming a completed workbook.

Excluding prior-batch O4 yields four delivered IDs; O2 retains S1 and S2 membership. At an inclusive 21:00Z boundary, 17:00-04:00 qualifies; 20:59:59Z does not. Missing O3 date remains unresolved.

## Decision briefs and proposal controls

Keep the brief's opening to decision, rationale, blockers and owner actions. When proposal management is requested, preserve schedule, accountable owners, pink/red review gates, amendment checks, deadline with timezone, final-file approval and submission confirmation controls. A compact capture brief must not erase these requested controls. For multi-page action tables, use repeated headers and heading/header-plus-first-row grouping; render the exact DOCX/PDF and inspect continuation pages.
